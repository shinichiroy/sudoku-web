# 機能仕様書 — 数独 Web App

最終更新: 2026-05-08  
対象バージョン: Phase 1 (MVP)

---

## 1. ゲームルール（数独の基本）

- 9×9のマス目をすべて1〜9の数字で埋める
- **各行**に1〜9がひとつずつ入る
- **各列**に1〜9がひとつずつ入る
- **3×3のブロック**（計9個）に1〜9がひとつずつ入る
- 最初から配置された数字（ヒント数字）は変更不可

## 3. 機能仕様

### 3.1 パズル生成

| 項目 | 仕様 |
|------|------|
| アルゴリズム | バックトラック法でランダムな完成盤面を生成後、マスを削除 |
| 一意解保証 | 削除するたびに解の個数を確認し、一意解を維持できない場合はスキップ |
| 生成空白数 | かんたん: 36マス / ふつう: 46マス / むずかしい: 55マス |
| 生成タイミング | 「新しいゲーム」ボタン押下時・初回ロード時 |

### 3.2 セル操作

| 操作 | 動作 |
|------|------|
| セルクリック | そのセルを選択状態にする |
| 数字パッド押下 | 選択中の空白セルに数字を入力 |
| キー 1〜9 | 選択中の空白セルに数字を入力 |
| Backspace / Delete / 0 | 選択中のセルの入力を消去 |
| 矢印キー（↑↓←→） | 選択セルを隣へ移動 |
| ヒント数字セルの操作 | 変更不可（無視される） |

### 3.3 ハイライト表示

| 種別 | 色 | 条件 |
|------|----|------|
| 選択セル | 水色 (`#bee3f8`) | クリックされたセル |
| 関連セル | 薄水色 (`#ebf8ff`) | 同行・同列・同3×3ブロック |
| ヒント数字 | 青文字 (`#2b6cb0`) + 薄青背景 | 問題で与えられた数字 |
| ユーザー入力 | 緑文字 (`#2f855a`) | ユーザーが入力した数字 |
| エラー | 赤文字 (`#c53030`) + 薄赤背景 | チェック機能で誤りと判定 |
| ヒント演出 | 紫フラッシュ | ヒントボタン使用直後 |

### 3.4 ヒント機能

- 選択中の空白セルに正解値を自動入力する
- ヒント数字として扱わず、ユーザー入力として記録する（緑表示）
- ヒント使用回数をカウントしてメッセージに表示する
- ヒント数字セルや既入力セルを選択中の場合はメッセージで通知

### 3.5 チェック機能

- ユーザーが入力したすべてのセルを正解と照合する
- 誤りがあるセルを赤くマークし、誤り数をメッセージ表示する
- 正解との照合のみで、マスの重複チェックではない

### 3.6 答え表示機能

- 確認ダイアログ（`confirm`）を表示する
- 承認後、盤面全体を正解で上書きする
- すべて「ユーザー入力」色ではなく正解盤面として表示

### 3.7 クリア判定

- ユーザー入力がすべての正解と一致したタイミングで自動検出
- クリアメッセージとヒント使用回数を表示

## 4. UI／UX仕様

### 4.1 レスポンシブ対応

| ブレークポイント | ボードサイズ |
|------------------|-------------|
| ≥ 480px | 最大 400×400px |
| < 480px | 画面幅 - 余白 |
| < 360px | 数字パッドのギャップを縮小 |

### 4.2 アクセシビリティ

- すべての操作をキーボードのみで実行可能
- セルのクリック・フォーカス対応
- コントラスト比: テキストと背景の比率 WCAG AA 準拠を目標

### 4.3 フォント

| 対象 | フォント |
|------|---------|
| 全体 | Segoe UI（Windows）/ Noto Sans JP（Android/Linux） |
| ボード数字 | 継承（上記と同じ） |

---

## 5. 非機能要件

| 項目 | 要件 |
|------|------|
| パフォーマンス | 問題生成（ふつう）< 500ms |
| 外部依存 | なし（CDN・ライブラリ不使用） |
| データ保存 | なし（Phase 1: セッション内のみ） |
| ネットワーク | 不要（完全オフライン動作） |
| セキュリティ | 外部入力なし・CSP未設定（静的ファイルのため低リスク） |

## 6. データ構造

### 盤面の表現

```js
// 0 = 空白、1〜9 = 数字
const board = [
  [5, 3, 0,  0, 7, 0,  0, 0, 0],
  [6, 0, 0,  1, 9, 5,  0, 0, 0],
  // ...
];
```

### ゲーム状態

```js
solvedBoard  // 正解盤面（生成時に固定）
givenBoard   // 問題盤面（ヒント数字のみ、空白は0）
userBoard    // ユーザーの入力状態（givenBoardのコピーに上書き）
selectedCell // { row: number, col: number } | null
hintUsed     // number（ヒント使用回数）
```

## 7. エラーケースと処理

| ケース | 処理 |
|--------|------|
| ヒント数字セルへの入力 | 無視（変更しない） |
| ヒント機能：空白セル未選択 | メッセージ「マスを選択してください」 |
| ヒント機能：ヒント数字セル選択中 | メッセージ「ヒントは空白マスに使えます」 |
| チェック：誤りなし | メッセージ「今のところ間違いはありません！」 |
| 答え表示：ユーザーがキャンセル | 何もしない |
