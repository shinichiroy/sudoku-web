# 数独 Web App

ブラウザだけで遊べるシンプルな数独ゲームです。  
サーバー不要・インストール不要。`index.html` をブラウザで開くだけで動作します。

## 概要

| 項目 | 内容 |
|------|------|
| 種別 | シングルページWebアプリ（SPA） |
| 技術スタック | HTML5 / CSS3 / Vanilla JavaScript（ES6+） |
| 外部依存 | なし（サーバー・ライブラリ不要） |
| 対応環境 | Chrome / Firefox / Edge / Safari（最新版） |
| モバイル対応 | レスポンシブデザイン対応（スマートフォン・タブレット） |

## 主な機能

- **ランダムパズル生成** — バックトラック法による一意解保証
- **3段階の難易度** — かんたん / ふつう / むずかしい（空白マス数で制御）
- **数字パッド入力** — マウスクリックまたはキーボード（1〜9キー）
- **メモ機能** — メモモードで候補数字を小さく複数書き込み可能（`m`キーでトグル）
- **元に戻す（Undo）** — 最大50手まで操作を取り消し可能
- **即時コンフリクト表示** — 重複した数字を入力した瞬間に赤くハイライト
- **4段階ハイライト** — 選択中 / 同一数字 / 関連マス（行・列・ブロック） / 通常
- **数字完了表示** — 9個すべて埋まった数字はパッドボタンが ✓ に変わり無効化
- **矢印キーでセル移動** — キーボードで快適にプレイ
- **ヒント機能** — 選択中のセルに正解を自動入力（使用回数バッジ表示）
- **はじめからやり直し** — 同じパズルをリセット

## 起動方法

```bash
# index.html をブラウザで開く（ダブルクリックでも可）
start sudoku-web/index.html
```
